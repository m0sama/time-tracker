# Competitors and alternatives

| Option | Strengths | Gaps for this use |
|---|---|---|
| Toggl, Clockify (free tiers) | Mature, good mobile apps, reports | Account required, built for teams and billing, more features than needed |
| Notes app or spreadsheet | Zero setup | No timer, manual arithmetic, easy to forget |
| Calendar blocks | Already in use | Poor for quick start and stop, no per-project totals |

**Takeaway:** the gap is a timer-first tool with no account, that runs in a browser and works on a phone. This MVP tests whether that is enough.
