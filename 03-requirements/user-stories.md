# User stories

1. As a person with several projects, I want to add a project by name, so that I can attribute time to it.
2. As a person who worked on something, I want to add a work entry with a date and hours, so that the time is recorded even if I did not track it live.
3. As a person logging time, I want hours in 15-minute steps, so that entries match how I think about time.
4. As a person who made a mistake, I want to edit or delete an entry, so that my totals stay accurate.
5. As a person checking progress, I want to see total hours per project, so that I know where my time went.
6. As a person working on one project, I want to open it and see its entries, so that I can review what I did.
7. As a person on my phone, I want a large + button to add an entry, so that logging takes one tap.
8. As a person who wants a backup, I want to export my data as JSON, so that I do not depend on one browser.
