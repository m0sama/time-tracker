# Success metrics

The MVP is a success if the following are true. These are about the loop, not about user growth.

1. **Loop complete:** the app is live on a public HTTPS URL that I can open on my phone.
2. **Used for real:** I log at least one work entry per working day for two weeks.
3. **Reliable:** no lost entries across a normal week of use, and the export works.
4. **Fast enough:** adding an entry from the home screen takes three taps or fewer (+, hours, Save).
5. **Repeatable:** I can ship a change (edit, test, redeploy) using the same checklist in `release/checklist.md`.
