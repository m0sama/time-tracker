# User flows

## Add a project
1. On the home page, type a name under **New project**.
2. Tap **Add project**. It appears in the list with `0 h`.

## Log a work entry
1. Tap the **+** button.
2. Choose a project, check the date (defaults to today), and enter hours in 0.25 steps (for example `1.5`).
3. Optionally add a note.
4. Tap **Save**. The entry appears on the project page and totals update.

## Log from a project page
1. Open a project from the home page.
2. Tap **+**. The project is already selected.
3. Complete the form as above.

## Edit an entry
1. Open a project and tap the entry.
2. Change date, hours, note, or project. Tap **Save**.

## Delete an entry
1. Open a project and tap the entry.
2. Tap **Delete**, then confirm.

## Back up
1. Tap **Export data (JSON)** (export is on the home page).
2. A file downloads.
